# Adv_Python_VM

A practice repository for learning Git and Python virtual environments.

## What's inside
- Git basics: clone, commit, push
- Virtual environment setup with `venv`

## How to set up
1. Clone the repo
2. Create a virtual environment:
                                 python3 -m venv venv
3. Activate it:
                                source venv/bin/activate
